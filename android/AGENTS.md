# TrackerHeart Android app

The native Android app (Kotlin + Jetpack Compose), opened in Android Studio. It is one of three TrackerHeart
apps in this monorepo; the web app in `../web/` is the reference
implementation.

Before writing code here, read the repo-wide guide and the plan. The plan
covers project setup, the Firestore contract this app must follow, and which
web files each part of this app ports:

- `../docs/monorepo-plan.md`
